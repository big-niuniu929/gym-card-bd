# 社群转化与售后 SOP

熟人市场的特点：传得快，也传得坏。一条对不上的价格能抵掉十张海报。

## 冷启动：三句话

1. **我是谁**：本校学生，自己在练，不是门店的人
2. **卡是什么**：门店的卡，价格见这张表，门店前台问到的和表上一样
3. **出了事找谁**：找我。卡开不了、想换课、时间对不上，先找我，我去门店争

第 2 句是最关键的：它给了对方一个**可验证**的动作（去前台问），信任从可验证里来，不从话术里来。

## 一对一匹配（不做群发）

| 对方说的 | 先问什么 | 再推什么 |
|---|---|---|
| 「想练练看」 | 一周能来几次？能坚持多久？ | 单次体验 / 月卡 |
| 「怕办了不去」 | 有没有同伴？住得远不远？ | 季卡 + 转卡条款 |
| 「想减脂/增肌」 | 要不要私教？预算多少？ | 季卡 + 私教体验 |
| 「能不能便宜点」 | 几个人一起？ | 团购档（3 人成团） |
| 「我室友也想去」 | 3 人够不够？ | 团购档 + 每人赠送 |

匹配的原则：**先问使用场景，再给档位**。先报价格，对方只会问「能不能再便宜」。

## 成交留痕（当时没做，现在补上）

每成交一单记一行：

```
日期 | 姓名/昵称 | 档位 | 金额 | 支付方式 | 卡号 | 提成口径 | 售后状态
```

一行都不用多，但它能在事后回答「到底发生了什么」。这个项目最大的缺口就是这张表从来没建过——所以只能讲过程，不能讲收益。

## 售后处理

| 问题 | 处理顺序 |
|---|---|
| 卡开不了 / 激活失败 | 先找门店前台核卡号 → 当场解决；超过一天升级到店长 |
| 想换课 / 换时间 | 按门店规则换；规则没写的，我去谈，不让同学自己聊 |
| 想退卡 | 按表里的退改规则走；能退则退，不能退说清依据，不拖 |
| 门店不认账 | 拿出报价表 + 聊天记录 + 卡号，直接找店长；仍不认就退到「我这边的差价补偿」 |

售后原则：**当天回，不拖**。熟人市场拖一天就会变成「他收了钱不管人」。

## 复盘要点

- 哪一档卖得最多，说明需求在哪
- 哪一档一次没卖出去，说明定价或人群判断错了
- 售后问题集中在哪个环节，说明表里少写了一条
