# 谈判要点

去谈的是三件事，顺序不能乱：**独家 → 口径 → 提成**。前两件谈不下来，这件事就不成立。

## 1 · 独家（先谈这个）

**为什么先谈**：没有排他，我做的所有内容引流都会变成门店的自然流量，价格还会被别人打穿。

| 要谈到的 | 具体说法 |
|---|---|
| 校区范围 | 「本校及周边 X 公里内的学生客群」写进约定，不写「学校附近」这种模糊表述 |
| 排他对象 | 门店不再给校内其他人同样的分销价；包括门店自己的员工私接 |
| 期限 | 先谈一个期限（一个学期/一个旺季），到期看数据再续 |
| 违约 | 如果门店给别人更低的价格，我这边的存量客户按同价补齐 |

**底线**：不给排他，就只做「先问价再决定」的轻模式，不投入内容与社群运营。

## 2 · 口径（第二谈）

**为什么第二谈**：价格口径不清，售后每一条都会变成价格解释。

| 要谈到的 | 具体说法 |
|---|---|
| 我能对外报的价 | 明确「最低可报到多少」，以及能不能公开写出来 |
| 卡种与权益 | 办多久、送几节、能不能转卡、能不能停卡——一条条落到纸上 |
| 退改规则 | 开卡前/开卡后分别怎么退，谁承担手续费 |
| 价格调整 | 门店要调价时提前几天告知，已成交的按原价执行 |

**底线**：口头承诺不算。门店店长换人很常见，上一任的口头承诺下一任不认。

## 3 · 提成（最后谈）

| 要谈到的 | 具体说法 |
|---|---|
| 比例与阶梯 | 按单还是按流水；做到多少单上浮 |
| 结算时点 | 成交即结 / 卡激活后 / 月末统一 |
| 退款扣回 | 退一单从下期提成里扣回，写清 |
| 自己人成交 | 同学的朋友算谁的 |

## 谈判姿态

- **不装成机构**：学生身份是优势，不是短板。说清「我是谁、卡是门店的卡、我拿提成、售后找我」
- **先给方案再要条件**：带着「我能带来什么」去谈（社群人数、内容能力、售后承接），不是先要独家
- **敢走**：谈不成没有损失。这一点在谈判桌上表现为「不着急」，比什么都管用

## 事后复盘

第一次谈的时候，我把「独家」放在最后，结果先谈了提成，再回头要排他要多花一轮。顺序是有成本的。
