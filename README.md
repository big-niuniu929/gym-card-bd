# 校区健身卡分销 · 一次完整的 0 → 1 成交

> 自己找上门谈下校园独家分销权，经手 **18,680 元**代收流水（实测）、**22 单**（实测）、**0 起**客诉/退费（实测，是记录不是凭证）。
> 2025.07–2025.08，约 1.5 个月，一个人做完谈判、报价、社群匹配、售后。
>
> 案例页（完整推理过程）：**https://big-niuNiu929.github.io/work/gym-bd.html**

18,680 元是**代收流水**，钱从我手上过、进的是门店的账；我拿的是提成，提成金额没有记录，所以这里不写个人收入。

---

## 需求是我自己发现的，不是别人委托的

校内和校门口那几家健身门店几乎只靠自然客流：路过的人进来问价，问完走了，就没有下一次。校园客群离得近，但门店没有任何一个动作是专门对着这群人做的。

我这边正好反过来：手上有健身社群的人脉，认识一批本来就在练、或者想开始练的同学。

一边有卡和价格，一边有需求和信任，中间缺的那个人一直不存在。缺的不是海报，是一个能对同学负责的人——问价、比价、办卡、卡出了问题，都找得到人。

## 关键差别：这件事属于谁

如果是门店委托我卖卡，我的角色就是执行：给我价格，我转发，拿返点。

实际情况是我先算好学生能接受的价格带，写清我能做什么、能担什么，再去说服门店把校内的独家给我。谈的是三件事：**校区范围内的独家 / 卡种与对外报价的口径 / 提成怎么算**。前两件谈不下来，这件事就不成立。

这条差别决定后面所有事都由我自己扛：没有预付款，没有雇佣关系，执行成本和售后风险全在我身上。

## 做了什么

| 动作 | 具体做法 |
|---|---|
| **陌拜谈判** | 要排他：校区分销只走我这条线，门店不再给别人同样的价格 |
| **报价表** | 门店原来的价格是口头说的（办多久、送几节、能不能转卡、能不能停卡全在店长嘴里），整理成一档一行：有效期、适用范围、赠送项、退改规则 |
| **私域匹配** | 自建社群，一对一按需求匹配卡种；报价口径只认那张表 |
| **售后全流程** | 卡开不了、想换课、时间对不上，先找我；没有工单系统，只有聊天记录 |

## 最难的一点：把口头报价变成可复述的对外口径

门店的价格天生是活的：店长看人给价，熟客多送两节，遇到难缠的再让一点。这种弹性在线下没问题，搬到社群里就是灾难——熟人社群一定会互相问价，同一个卡种两个人问到两个数，信任立刻塌，而且塌得没有补救办法。

处理方式是把口径写死：所有能让的东西提前放进表里，表外的让步一律不做。同时正面处理「没有品牌背书」：不装成机构，说清楚我是谁、卡是门店的卡、我拿的是提成、售后找我。

冷启动的信任不是靠话术，是靠一句能被验证的话：**你先去前台问，问到的和表上一样。**

## 结果

| 项目 | 数字 | 标记 | 口径 |
|---|---|---|---|
| 代收流水 | 18,680 元 | 实测 | 2025.07–2025.08 经手代收的销售额；不是我的收入 |
| 成交单量 | 22 单 | 实测 | 同一时间窗；自建报名名单 23 条，差额是未成交的询问 |
| 客诉 / 退费 | 0 起 | 实测 | 当天记录与名单核对得出，没有工单留存，所以是记录不是凭证 |

「业绩集中在 2–3 天」是本人自述，没有按日记录，标**待核实**，不当作结论。

## 没做到的

- **收入结构不健康**：纯提成、没有底薪、旺季只有几天，是一次性窗口，不是可持续经营的生意。做完一轮就没继续做。
- **证据链自己弄断了**：没有收款流水、没有提成结算记录、没有社群截图，所以只能证明「钱从我手上过」，不能证明「我拿到了多少」。
- **报价表是吃过亏之后才整理的**：第一轮靠嘴报价，口径在脑子里。凡是只能装在自己脑子里的口径，都不算口径。
